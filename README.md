# הקרפטים 2026 🏔️ — אפליקציית הטיול

אפליקציית PWA לטיול המשפחתי ברומניה (20–29.9.2026). עובדת מלא באופליין אחרי פתיחה ראשונה, על אנדרואיד ואייפון.

## מה יש בתיקייה

| קובץ | תפקיד |
|---|---|
| `index.html` | האפליקציה כולה — עיצוב, לוגיקה **וכל תוכן הטיול** (אזור ה-DATA בראש הסקריפט) |
| `sw.js` | Service Worker — שומר הכול במכשיר לעבודה אופליין |
| `manifest.webmanifest` | הגדרות ההתקנה (שם, אייקון, צבעים) |
| `icon-*.png`, `apple-touch-icon.png` | אייקוני האפליקציה |

## פריסה (5 דקות)

חייבים אירוח עם **HTTPS** (דרישה של Service Worker). שתי דרכים קלות:

**דרך 1 — Netlify Drop (הכי מהיר):**
1. נכנסים אל https://app.netlify.com/drop
2. גוררים את כל התיקייה `carpathians2026` לדפדפן
3. מקבלים כתובת כמו `https://something.netlify.app` — זהו, זו האפליקציה

**דרך 2 — GitHub Pages:**
1. יוצרים ריפו (אפשר פרטי עם Pages), מעלים את הקבצים
2. Settings → Pages → Deploy from branch → main
3. הכתובת: `https://<user>.github.io/<repo>/`

> 🔒 **פרטיות:** בקבצים יש מספרי הזמנות וקוד כניסה למלון. לשלוח את הקישור רק לחברי הקבוצה, לא לפרסם.

## התקנה על הטלפונים (לשלוח לכל המשפחה)

**אייפון:** פותחים את הקישור ב-**Safari** → כפתור שיתוף (הריבוע עם החץ) → **הוסף למסך הבית**.

**אנדרואיד:** פותחים את הקישור ב-**Chrome** → תפריט ⋮ → **התקנת אפליקציה** (או "הוספה למסך הבית").

חשוב: לפתוח את האפליקציה **פעם אחת עם אינטרנט** — מאותו רגע הכול שמור ועובד גם בלי קליטה בהרים.

## עדכון תוכן (למשל: נסגרה לינה בבושטני)

1. עורכים את אזור ה-`DATA` בראש `index.html` (אובייקטים `DAYS`, `STAYS`, `OPEN_ITEMS`, `GEAR`)
2. ב-`sw.js` מעלים את מספר הגרסה: `carpathians-v1` → `carpathians-v2`
3. מעלים מחדש לאירוח
4. כל מי שיפתח את האפליקציה עם רשת יקבל הודעת "יש גרסה חדשה — רענון"

## ניווט בשטח

האפליקציה מחזיקה את קישורי המסלולים, אבל הניווט עצמו נעשה ב-**Mapy**: כל משתתף מוריד מראש באפליקציית Mapy את מפת רומניה לאופליין (זה כבר ברשימת הציוד 🙂).
